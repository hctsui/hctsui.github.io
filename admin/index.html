English中文操作

保存方式：每次編輯會即時保存於這台裝置的瀏覽器。完成後按「複製 JSON 並開啟 GitHub 編輯器」，在 GitHub 頁面全選原內容、貼上並 commit；不需要建立 Issue，也不會逐列等待 Action。

排序方式：先選擇 Conference、Talk、Visit、Honor、Publication 或 Teaching 其中一類，再按「開始網站排序」。Publication 與 Teaching 可調整大標題及項目；其他類別可調整所有項目。儲存後貼到自動開啟的表單，網站與 CV 會使用同一順序。
