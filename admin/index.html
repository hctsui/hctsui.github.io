網站批次管理

新增、修改、刪除、排序、中英對照表與垃圾桶還原都先保存在瀏覽器；確認預覽後，一次送出一張 GitHub 批次表單。

論文／作品與教學會保留作品類別／機構，只排序各類別或機構內的項目；套用後仍可用上下箭頭微調。

每筆操作可在套用後 7 天內預覽並加入還原草稿；若物件後來又改過，後端會阻止覆蓋。到期後 Admin 會停止顯示與還原；目前過期紀錄會在下一次批次更新時才從 change-history.json 清除，並非準時排程刪除。

完整欄位一對一比對，不做關鍵字、模糊或 AI 翻譯。每個詞條可有多個標籤；同時選取多個標籤時，只顯示擁有全部所選標籤的詞條。

匯入字詞／標籤檔案

JSON 檔只會先變成瀏覽器中的草稿，不會直接修改 GitHub。讀取後會先驗證並顯示完整修改前後差異；按「套用為草稿」後，仍需使用一般批次送出流程。

安全合併會保留既有詞條，並合併匯入標籤。需要精確移除或改名時，匯入檔可使用 match、remove_pairs、remove_tags、tag_order；也可選擇完整取代。

例如同時選「機構／學校」「大學」「日本」，只顯示同時擁有這三個標籤的詞條。

標籤管理

可新增、修改顯示名稱、合併、刪除及調整順序。這裡的順序也就是篩選列和詞條標籤的顯示順序。

全站標題管理

集中管理首頁、CV、Publications、Activities、Teaching 的中英文大標題、小字與頁面簡介。與 PDF CV 共用的標題會同步套用；預設值與目前網站完全相同。
