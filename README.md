# hctsui.github.io

Academic website of Hung-Chun Tsui.

中文操作說明：[`MANAGE-WEBSITE.md`](MANAGE-WEBSITE.md)  
管理頁：<https://hctsui.github.io/admin/>

The CMS uses a schema-3 page/category/item model. Every managed item belongs to a movable bilingual category; the same category data drives both websites and the English/Traditional-Chinese PDF CVs. Conference and Organization records are independent.
