# hctsui.github.io

Academic website of Hung-Chun Tsui.

## Content management

The current visual design remains in the existing HTML and `assets/style-v23.css`. Repeating content is stored in `content/site.json` and managed through GitHub Issue Forms.

中文操作說明：[`MANAGE-WEBSITE.md`](MANAGE-WEBSITE.md)

管理頁：<https://hctsui.github.io/admin/>

The generator changes only content between invisible `<!-- CMS:... -->` markers. Existing CSS, JavaScript, page copy, navigation, and layout are not regenerated.
