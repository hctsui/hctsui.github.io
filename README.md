Eyebrow-label rule:
1. A page-level eyebrow states the scope of that page.
2. An internal eyebrow states the type of records shown in that section.
3. It must add information and must not repeat or merely paraphrase the large heading.
4. English and Chinese use natural wording rather than literal translation.

Examples:
- Research record / Publications
- Manuscripts / Preprints
- Academic record / Activities
- Talks / Presentations
- Participation / Conferences and Workshops
- 教學紀錄 / 教學
- 任教機構 / 國立清華大學
