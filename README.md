# hctsui.github.io

Multi-page academic website for GitHub Pages.

Pages:
- `index.html` — homepage
- `publications.html` — complete publications
- `activities.html` — visits, presentations, awards, conferences
- `teaching.html` — teaching assistantships

Shared files:
- `assets/style.css` — layout and color palette
- `assets/script.js` — mobile menu and bilingual toggle

Upload every file and folder to the root of the `hctsui.github.io` repository.
